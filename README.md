# 💪 FitCore Gym Landing Page

## 📌 Overview

FitCore Gym is a modern landing page designed to showcase a fitness center in a clean, structured, and engaging way.
The website highlights the gym’s services, strengths, and community while encouraging users to join through a clear and user-friendly interface.

---

## 🎯 Purpose

The main objectives of this project are to:

* Create a strong first impression
* Present the gym’s key features and benefits
* Build trust through user testimonials
* Encourage users to register via a membership form

---

## 🛠️ Tech Stack

* HTML5
* CSS3
* Google Fonts (Inter)

## 🧩 Key Sections

### 🔹 Hero Section

A visually engaging introduction that includes a headline, description, call-to-action buttons, and an image to capture user attention.

### 🔹 Why Choose Us

Highlights the gym’s unique features and advantages, helping users understand its value.

### 🔹 Testimonials

Displays feedback from members to build credibility and trust through social proof.

### 🔹 Membership Form

A structured form that allows users to submit their information and start their fitness journey.
